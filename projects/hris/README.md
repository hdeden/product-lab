# HRIS Project

## Overview
- Mobile-first HRIS for Indonesian UMKM in cafe and security sectors.
- Focus on attendance, leave, payroll basics, and employee self-service.
- Multi-tenant SaaS with Flutter apps and Supabase backend.

## Current Status
- Research and design docs are established.
- MVP scope and system design defined.
- Execution checklist and progress logs tracked in docs.

## Structure
- docs/: research, requirements, specs, plans, and logs.
- app_flutter/: Flutter client (employee app + admin web targets).
- supabase/: database migrations, RLS, and local setup.
